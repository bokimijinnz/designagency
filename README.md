# WHETŪ Studio — 디자인 에이전시 웹사이트

견적 요청 → 내가 검토·견적 → 고객 수락 → 계약금 → 디자인/피드백 → 잔금 → 최종 파일 전달까지
**모든 과정이 웹사이트 안에서** 이뤄지는 디자인 스튜디오 사이트예요. 앱이 아니라 일반 웹사이트(HTML · CSS · JS)입니다.

## 페이지

| 파일 | 누가 보나 | 내용 |
|---|---|---|
| `index.html` | 모두 | 홈 (히어로, 진행 방식, 가격, 주요 작업, 저널) |
| `estimate.html` | 고객 | 7단계 견적 폼 + 실시간 예상 가격 → 요청 보내면 **접속 코드** 발급 |
| `work.html`, `project.html` | 모두 | 포트폴리오(프로젝트) 목록 / 상세 |
| `journal.html`, `post.html` | 모두 | 블로그 목록 / 글 |
| `login.html` | 고객 | 이메일 + 접속 코드로 로그인 |
| `portal.html` | 고객 | **My Studio 포털**: 진행 단계, 견적 수락/거절, 시안 선택, 수정 요청, 메시지, 파일 |
| `admin.html` | 나(스튜디오) | 요청함, 견적 작성·발행, 입금 확인, 시안/버전 올리기, 메시지, 파일, 비공개 메모, 블로그·포트폴리오 편집 |

## 고객과 나의 흐름

1. 고객이 견적 폼을 보냄 → `admin.html` 요청함에 **신규 요청**으로 뜸. 고객은 접속 코드를 받아 포털에 들어감.
2. 내가 브리프를 보고, 필요하면 **메시지**로 질문 → 견적 항목/일정/결제 링크를 입력해 **견적 발행**.
3. 고객이 포털에서 견적을 **수락**(또는 질문/거절).
4. 계약금 50%가 들어오면 내가 **계약금 확인** → 디자인 단계 열림.
5. 내가 **시안 방향(최대 3개)** 을 이미지로 올림 → 고객이 하나 선택.
6. 고객이 **수정 의견(회차당 한 번에)** 을 보냄 → 내가 **새 버전**을 올림. 기본 2회 포함, 초과 시 회당 $150 추가(잔금에 합산).
7. 고객이 **디자인 승인** → 내가 최종 파일 업로드 → 잔금 확인 → 고객이 파일 다운로드.

메시지와 파일 공유는 모든 단계에서 가능해요. 읽지 않은 메시지는 빨간 배지로 표시돼요.
화면은 English / 한국어 / 中文 전환이 돼요.

## 실행 방법

### A. 데모 모드 (설치 없이 바로)
`index.html`을 브라우저로 열거나 아무 정적 호스팅(GitHub Pages, Netlify 등)에 올리면 돼요.
데이터는 **그 브라우저에만** 저장돼요. 같은 브라우저에서 탭 두 개로 `portal.html`과 `admin.html`을 열면 양쪽을 다 체험할 수 있어요.
데모 모드에서는 **자동 로그인**돼요. 상단 메뉴의 **고객 로그인**(고객 화면)과 **디자이너 포털**(내 화면)로 양쪽을 오갈 수 있고, 처음 열면 샘플 프로젝트 하나가 만들어져요.
실제 운영 전에는 `js/config.js`에서 `demoAutoLogin: false`로 바꾸세요 (서버 모드에서는 원래 적용되지 않아요).
> 실제 고객용이 아니에요. 고객과 내가 서로 다른 기기에서 보려면 B를 쓰세요.

### B. 실제 운영 (서버 모드)
Node.js 18 이상만 있으면 돼요 (추가 설치 패키지 없음).

```bash
ADMIN_PASSWORD='긴-비밀번호' npm start      # http://localhost:8080
```

- 서버가 켜져 있으면 사이트가 자동으로 서버 모드로 바뀌어요.
- 데이터: `server/data/` (요청·메시지 `db.json`, 업로드 파일). 백업하세요. git에는 올라가지 않아요.
- 환경변수: `PORT`, `ADMIN_PASSWORD`(필수), `DATA_DIR`, `MAX_UPLOAD_MB`(기본 25), `STUDIO_EMAIL`.
- Render, Railway, Fly.io, VPS 등 **디스크가 유지되는** 곳에 HTTPS로 올리세요.

## 바꿔야 할 것

- **스튜디오 이름·연락처**: `js/config.js`
- **가격**: `js/estimate.js`의 `SV`(시작가)와 `calc()`(항목별 금액), 홈 가격표는 `index.html`
- **추가 수정 회차 가격 / 포함 횟수**: `js/workflow.js`의 `CFG`
- **블로그·포트폴리오**: `admin.html` → Journal / Work에서 작성·편집. 지금 들어있는 글과 프로젝트는 모두 **샘플**이에요 (`js/data/seed.js`).
- **이메일 알림**: 지금은 서버 콘솔에 "누구에게 무엇을 보낼지"만 출력돼요 (`server/server.js`의 `notify()`). Resend, Postmark 같은 서비스를 연결하면 고객에게 접속 코드·새 메시지 알림을 보낼 수 있어요.
- **결제**: 견적 작성 시 결제 링크(Stripe Payment Link 등)를 넣으면 고객 포털에 "결제" 버튼이 생겨요. 입금 확인은 내가 관리자에서 눌러요.

```
css/   base.css(공통) home.css estimate.css content.css(블로그·작업) portal.css admin.css
js/    config.js           설정
       i18n.js, i18n-app.js 번역 (영/한/중)
       workflow.js          프로젝트 단계 규칙 — 브라우저와 서버가 같이 씀
       api.js               데이터 저장 (서버 모드 / 데모 모드 자동 선택)
       common.js            헤더·푸터·언어·마크다운
       home.js estimate.js content.js login.js portal.js admin.js project-ui.js
       data/seed.js         샘플 블로그 글·프로젝트
server/server.js           의존성 없는 Node 서버 + API
assets/img/                마스코트 이미지 (원본 HTML에 들어있던 것을 파일로 분리)
```
